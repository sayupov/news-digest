# News Digest (облегчённая версия)

Ежедневный отчёт в Telegram: главные новости по вашим направлениям, инструменты для пробы и предстоящие
мероприятия. По воскресеньям приходит недельный обзор. Работает бесплатно на GitHub Actions.

## Что в отчёте
- **ГЛАВНОЕ** (до 5 новостей, в недельном обзоре до 8): перевод заголовка, дата, источник и его тип, факт,
  анализ, применение, приблизительная оценка 1-10, ссылка.
- **ИНСТРУМЕНТЫ ДЛЯ ПРОБЫ** (до 3, только если есть что показать).
- **ПРЕДСТОЯЩИЕ МЕРОПРИЯТИЯ** (до 5): только по теме (ИИ-агенты, GovTech, AgriTech, хакатоны, а также события
  в Казахстане). Общие вендорские вебинары отсеиваются.
- В недельном обзоре дополнительно: тренды недели и до трёх действий.
- В конце две-три строки контроля: сколько источников открылось, что отклонила проверка, по каким
  направлениям нет материалов.

## Как это устроено и что проверяется
1. Скрипт читает RSS-ленты и календарь, убирает повторы и уже опубликованное (память в `state.json`).
2. Gemini выбирает и пересказывает материалы. Каждый пересказ обязан содержать дословную цитату из текста
   источника. Программа проверяет, что цитата реально есть в тексте, и что в пересказе нет цифр, которых нет
   в источнике. Не прошедшее проверку в отчёт не попадает.
3. Если одна модель Gemini недоступна или не отвечает, скрипт пробует следующие. Если не отвечают все,
   приходит короткий резервный выпуск с заголовками.

**Ограничения.** Независимая проверка по другим источникам не выполняется. Проверка цитат доказывает привязку
к тексту источника, а не истинность заявлений компаний. Оценка 1-10 приблизительная, её даёт модель.
Тип источника определяется по списку в коде (`SOURCE_TYPES`).

## Файлы
- `digest.py` скрипт (только стандартная библиотека Python).
- `config.json` настройки: часовой пояс, лимиты, ленты `feeds`, календари `event_calendars`.
- `.github/workflows/digest.yml` расписание: 08:00 каждый день и 17:00 по воскресеньям (UTC+5).

## Секреты (Settings -> Secrets and variables -> Actions)
`GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`. Необязательно: переменная (Variables)
`GEMINI_MODEL` с названием модели, которую пробовать первой.

## Как обновить
Замените `digest.py`, `config.json` и `.github/workflows/digest.yml` в репозитории (значок карандаша ->
вставить текст -> Commit changes). Старые файлы `tests` и `CHANGELOG.md`, если они есть, можно удалить.
Затем: Actions -> News digest -> Run workflow. Флажок `dry_run` показывает пробный запуск без отправки.

## Если что-то не работает
В журнале запуска (Actions -> запуск -> шаг «Сформировать и отправить отчёт») есть строки о том, какие
ленты не открылись и какие модели не подошли. Адреса лент в `config.json` не все проверены: недоступные
будут названы в конце отчёта.
